# VARPEC AUTOMATIONS

Premium B2B automation agency website — built with React, Vite, Three.js, Framer Motion, and GSAP.

## Features

- Cinematic hero with interactive 3D scene (react-three-fiber)
- Editorial laptop showcase sections
- WhatsApp-linked CTAs
- Full agency-grade SEO (sitemap, robots, 5 JSON-LD schemas, OG/Twitter cards)
- Responsive mobile-first design
- Dark theme with orange brand accent

## Stack

- React 18
- Vite
- Three.js + @react-three/fiber
- Framer Motion + GSAP
- Lucide icons

## Development

```bash
npm install
npm run dev
npm run build
```

## Deploy

Optimised for Vercel / Netlify / Cloudflare Pages (static SPA).
